# Shashank C J — Developer Portfolio

Responsive React + Vite portfolio starter.

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the URL Vite prints, usually http://localhost:5173.

## Production build
```bash
npm run build
npm run preview
```

## Personalize before publishing
Edit `profile` near the top of `src/main.jsx`:
- Replace `YOUR_EMAIL@example.com`
- Replace `YOUR_GITHUB_USERNAME`
- Replace `YOUR_LINKEDIN_PROFILE`
- Put your actual resume PDF at `public/resume.pdf`

Review project and experience details, and add only claims you can explain in an interview. Add actual repository/demo links and screenshots when available.

## Deploy
Push to GitHub and import into Vercel or Netlify. Use `npm run build` and `dist` as the output directory.

No backend is required. This portfolio does not store visitor information.
